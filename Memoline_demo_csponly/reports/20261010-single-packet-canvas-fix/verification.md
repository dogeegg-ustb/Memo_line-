# 单差异包画布入口越界修复

实际会话 `fd6f70ac62a6488b9b0ac73444792876` 的当前图层只有一个差异包。读取器给首包写入 Before 后，列表中的 record 已经改变；再用分组中的旧末包对象执行 IndexOf，得到 -1，访问 result[-1] 时抛出 `ArgumentOutOfRangeException`。实际会话只读诊断与新增模拟回归均在修复前复现同一堆栈：`LiveSessionReader.ReadPackets` 原第 112 行。

修复先取得首尾两个列表位置，再写入 Before 和 Current。写 Current 时基于列表当前 record，因此首尾同槽时保留已加载的 Before。单包回归使用不同的起始及当前像素，同时断言两者，覆盖越界与快照字段被覆盖两个风险。

最终验证：

- Release 检查构建 0 警告、0 错误。
- 直接执行检查 EXE：PNG/会话读取 25 项通过，面板选择 50 项通过；画布状态、撤销容量、宿主契约、画布交互和笔刷参数的相关检查通过。
- 同一次实际失败会话读取成功：当前差异包 1 个，工程历史会话 1 个，组合索引 259 笔、1 张脏矩阵。原录制和工程只读。
- 只读独立代码审核通过。
- 进入画布失败时，宿主现将完整异常堆栈写入 watcher.log，面板仍显示简短错误。

## 功能语义

预览只计算选笔、显示白线及重建方案，不执行 CSP 重建。精确撤销选取当前图层选区内可见表层候选中的最近最多 50 笔作为基础，加入后续写入重叠闭包，总数可以超过 50；执行先构建去掉这些笔画的底图，再逐笔画回原笔以形成 CSP 撤销栈顶，随后 Ctrl+Z 逐笔撤销，需确认总笔数 + 5 的撤销容量。事件编辑按脏矩阵选取完整笔接触，执行删除或覆盖参数/子工具，合成可信像素并重放必要依赖。原图层隐藏保留。
