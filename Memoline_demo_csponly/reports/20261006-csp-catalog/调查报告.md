# 本机 CSP 配置与 Memoline 属性库对照

已只读检查本机 CSP 5.0.0.0 的 `EditImageTool.todb`、安装翻译资源，以及当前保存的 `D:\感官解冻原画及参考\插画6.clip`。没有修改 CSP 配置或绘画内容。

本机配置有 264 个目录节点、203 个具体子工具、406 个参数版本，`Variant` 表有 508 列。203 个子工具逐项列在 [subtool-coverage.csv](subtool-coverage.csv)，各自当前保存版本的全部非空字段、数值、未关联项、可见属性原始编号和动态数据摘要在 [configuration-audit.json](configuration-audit.json)。144 个子工具保存了笔刷尺寸，其中也包含图形等工具，不能将它们全部视为自由绘画笔刷。

## 确认的问题与修改

| 问题 | 证据及结果 |
|---|---|
| 翻译资源版本不一致 | 原库标注 CSP 2.0.0；本机为 5.0.0.0。旧分组 `(1,22)` 已不再是笔刷控件主体，本机主要控件在 `(1,23)`。导入脚本改为按控件名称定位分组。 |
| 缺少当前简体译名 | 本机资源 `(1,23,1,169)` 明确为 `Vector eraser / 矢量擦除 / 刪除向量`。更新后 82 项已有定义增加新译名，相关分组收录 1573 个短 UI 字符串、12 种语言。UI 字符串不是参数定义，也不是私有参数编号。 |
| 颜色变化子属性缺失 | 原来只记录“更改前端颜色／每笔触随机”的复合父项，缺少两组色相、饱和度、明度、副色混合数字子项。补充八项后为 158 个定义，均带简短含义、状态说明和来源。同名标签需有当前截图中的父标题，缺少上下文时保持未确认。 |
| 属性面板名称误读 | 历史失败截图将菜单符号读成“三”，即使工具目录中存在“較硬”也没有匹配。现在首先匹配属性名称，失败后从同次采集的子工具面板唯一高亮子工具行兜底。高亮大类／组标题单独处理，保存选中项不作为实时证据。 |
| 抗锯齿漏字 | 历史截图漏识别“中”，其高亮单元格仍清晰可见。已用识别出的“无、弱、强”定位四档布局，恢复第 3 项“中”；选项漏读也不会使“强”错误变成第 3 项。 |
| 硬度控件语义错误 | 历史截图是五格中的前三格累积填色，旧算法记为第 1 项；现在记为第 3 格，保留图标分类。该截图与保存配置中的 `BrushHardness=60`相符，但未把图标位置当作数字输入位置。 |
| 图层混合模式缺项 | 补充“减去、深色、浅色、除法”，修正“添加（发光）”被错误称作“线性减淡”的映射。图层词库现在有 29 项。 |

## “較硬”的实际核对

| 项目 | 本机保存配置 | 实际截图的新识别 |
|---|---|---|
| 子工具 | `tool_89`，橡皮擦大类 `tool_87`，组 `tool_88` | 唯一高亮子工具“較硬”，大类／组“橡皮擦”不混入 |
| 尺寸 | `BrushSize=27.200000000000003` | 27.2，独立数字位置 |
| 抗锯齿 | `AntiAlias=2` | “中”，界面第 3 项；数据库原值和界面序号不同 |
| 硬度 | `BrushHardness=60` | 五格累积指示器第 3 格 |
| 前端浓度 | `BrushFlow=100` | 100，独立数字位置 |
| 手颤修正 | `FlickerReduction=2` | 2，独立数字位置 |
| 矢量擦除 | `BrushUseVectorEraser=1`，模式代码 0 | 控件灰显，报告 `disabled`；没有据保存开关伪造实时 `checked` |

该子工具 181 个非空配置参数列均可关联到定义或相关子项。但这不等于 181 项实时状态已完整识别：动态曲线二进制数据仍只保留长度与哈希，关闭功能的保留值也不代表当前生效。

## 仍未完整支持的内容

- 144 个保存笔刷尺寸的子工具中，20926 个参数实例可关联到属性定义，1253 个实例未关联。主要属于图形、速度线、矢量编辑、气球和其他工具的额外参数；每个工具的具体字段在 CSV 和 JSON 中完整列出，没有默认为零或删除。
- `VariantShowParam` 的私有编号仍未映射为当前面板可见性；它与翻译资源 ID 不是同一套编号。复合开关、模式和动态曲线也不能凭一个标量宣称全部确认。隐藏属性没有当前数字位置，回放器不会尝试编辑。
- 图层属性库补充了 25 组属性／效果的含义及支持说明。现有保存文件核心完整提供其中 9 组，蒙版组部分提供，15 组尚未读取完整状态：参考标记、透明像素锁定、面板颜色、边缘／水彩边缘、线稿提取、网点、图层颜色、表现颜色与阈值、减少颜色显示、蒙版表现、工具导航、纹理叠加、拷贝台颜色。当前图层接口仍确认名称；结构和详细已支持字段来自保存后的 `.clip`，描述的存在不代表对应实时值已采集。
- 本机保存文件有 3 个图层、57 个图层表字段。字段和当前可读取值在 [layer-configuration-audit.json](layer-configuration-audit.json)。`LayerColorTypeIndex` 等原始字段没有靠猜测解释成已确认的颜色状态。

## 验证与发布

128 项 Python 检查通过，覆盖名称兜底、目录重名、大类／组排除、当前采集身份、抗锯齿漏字、累积硬度、颜色子项上下文及原有接口。回放器 246 项断言通过，原始样本的 6 个聚集包和 28 个可回放笔操作仍可读取；同状态连续笔触不新增请求。Memoline 的 37 项公共接口检查及集成检查通过。

[ocr-verification-published.json](ocr-verification-published.json) 使用发布程序自带模型离线验证：历史属性截图与用户另附子工具截图分别作为输入，能确认“較硬”和上述值。二者不是同一历史时刻的截图；真实管线使用同一采集批次的伴随截图，该身份绑定另由管线测试验证。本次未向 CSP 注入实际回放操作。

发布入口：`D:\Memo_Line\Memo_Line\Memoline_demo_csponly\Memoline.exe`，`D:\Memo_Line\Memo_Line\replayer\packetreplayer\release\win-x64\PacketReplay.exe`。重新启动 Memoline 并开始新会话以加载更新后的识别代码和数据库。
