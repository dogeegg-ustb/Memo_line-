# RGB、录制中编辑及工程续写

本次修改延续 2026-10-07 的整合代码，连接 Memoline 宿主、watcher、共享剪贴板图像编码和 packetreplayer。原有架构历史说明保留，本页反映当前状态。

## 用户流程

正常作画可使用色轮。使用编辑或精确撤销前暂停作画，在原色彩面板切换到 RGB 滑块并选中主色。Alt+M 打开编辑面板，建立刷盘边界，选择画布区域和事件，预览后执行。无需停录或重新标定颜色区域。

颜色读取依据当前截图中的 RGB 文字、彩色滑块、数字 OCR 框及主色胶囊选中轮廓。数字输入使用屏幕投影框；每次输入后的新截图须确认整个 RGB 值。未确认、位置越界、旧截图和副色均拒绝执行。给定的 393×258 RGB 截图实际 OCR 得到主色以及三个 0，数值框分别为 `[319,80,14,20]`、`[319,118,14,19]`、`[319,156,14,20]`。这些位置仅为样例识别结果，运行时重新识别。

## 事务与记录

边界暂停普通捕获请求，排空保存/差异任务并采集各层当前完整画布；读取原生 `.memoline.part` 的刷盘前缀，并展开同一工程已有 `.memoline` 的旧会话，形成工程编辑索引。原文件只读，历史快照和原生索引按文件内容哈希复用，当前前缀及捕获始终更新。执行前再次建立边界并复核选区和精确撤销闭包，避免覆盖面板打开后新增的绘画。

CSP 动作通过现有控制接口与已配置快捷键完成：保存后的 UUID/堆叠证据、隐藏源层、粘贴原样像素自检、整层导出、重建、检查点和资产刷盘、确认 UUID 后删中间层、保留最终复现层并注册 baseline。源文件由只读 Rust 桥读取。退出程序先取消面板操作并等待事务释放输入及捕获保护，再停录封盘。

原生事务期间排除自动输入、状态和打断的物理样本；诊断及实时 OCR 继续供校验。成功后只写一个带修改内容的“事件编辑”或“精确撤销”语义事件。打断不会假报成功；未入库工作层与失败检查点保留。复现结束后真实用户撤销正常入库。

## 同工程续写

按完整 CLIP 路径寻找原 `.memoline`，可从 v1–v3 的初始化配置认领工程身份。封盘以 v4 同一路径原子替换，保留所有先前单会话容器的原始机械字节、独立时钟、差异资产和编辑日志；不会每次创建编号文件。不同目录的同名工程用稳定路径摘要区分。

已有工程内的笔画现在参与录制中编辑。本次新增笔接触为零时，精确撤销和事件编辑也会查找旧会话的合格事件与表层图片。每笔保留源 `(SessionId, BeginAppendId)`、样本、状态及频率；封盘顺序另存 `SessionOrder`。图层唯一 UUID 映射到当前确认的 session/generation，保留源层身份；执行时按源会话恢复状态和轨迹，再使用当前 CSP 目标进行重建。冻结计划记录这些来源，封盘保存引用的历史机械流并验证日志引用，避免日后把旧编号误解释为本次录制编号。

接入历史前检查每层的完整像素与差异链，包括没有笔画的会话。相邻会话完整同尺寸 RGBA 不同的区域，以精确前后像素保留为没有事件归属的接缝图片。它覆盖旧表层并且不能选择为笔画。未知操作的读取范围可能超过变化区域或读取其他图层，因此修改差异到达这个间隔时仍未消除，就拒绝未知事件重放。间隔之后已完整记录的修改不受这个过去的未知操作阻断。缺完整图、尺寸不同或内部链损坏时仍拒绝。旧会话缺少末编辑边界，只有后续起点匹配或完整像素接缝成立时才有延续的像素证据，不能据此补出未知操作。

## 末尾封盘完整性

停止时主动恢复 CSP 并刷新 CLIP、图层和视口状态，原生结束标记等待最后接触完整结束和刷盘；随后从一次保存快照捕获各个涉及图层的整图和脏矩阵。当前层普通捕获不得消费其他层未保存的操作。所有末尾资产须在原生 footer 核验后提交；缺图、漏层或标记后新增文档输入拒绝封盘并保留原始文件。结束副层包只包含上下文机械指针，不重复声明主尾包的事件窗口。

实际旧文件尾部 84 笔已写入原生流，但结束包为 `empty`、脏矩阵为零，属于末次捕获失败仍发布封盘的 bug。新流程修正后续录制，不能为旧文件猜造丢失的图像。实际文件的历史选区与规划阻断详见 `reports/20261009-recording-tail/选区验证.md`。

## 验证与当前边界

普通历史撤销不再一律阻断重建。原生起笔/落笔和已配置快捷键按文档全局栈配对，撤销单位与可重放资格分开；连续撤销逐步弹栈，重做恢复原接触，新笔清空重做栈。已撤销笔画保留原始身份和样本，但退出当前可选范围。完整初始图和末整层图建立有效历史检查点，整张旧补丁不能继续覆盖重建结果。执行时先原样重放仍生效的笔画，像素一致后再执行修改；未知目标、其他文档操作或未还原的跨层参考仍拒绝。刷新同像素编辑边界保留逻辑检查点身份。长错误支持滚动和复制。代码与实际文件验证见 `reports/20261009-undo-history`。

自动检查只使用临时文件、fake CSP/管道和模拟输入。真实 CSP 的图层粘贴、隐藏 RGB 保真、数位板复现及真实 Ctrl+Z 验收尚未执行，须使用工程副本按 `LIVE_CHECKLIST.md` 操作。

实际用户提供的 `.memoline` 可直接用于文件内回归：代码选择真实历史范围，运行精确撤销与事件编辑的索引、计划和重建路径，比较真实资产产生的像素结果。此类验证不要求操作 CSP，也不等于实机通过。
