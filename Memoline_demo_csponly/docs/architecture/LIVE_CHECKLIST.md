# CLIP 副本实机验收清单

状态：实机待执行。最新交互与代码范围见 [2026-10-08 整改说明](2026-10-08-canvas-editing-corrections.md)。已接通冻结画布选区、跨层图片、白线整笔扫选、截图笔刷属性识别、撤销容量确认及已封盘工程历史的读取、选择、源会话调度和轨迹封存。跨会话未知变化按精确像素接缝保留，其影响范围不能猜测为可重放笔画。历史参考像素调度已接到事务，真实 CSP 指定参考角色及撤销栈内场景清理尚未完成。离线检查不能记为实机通过，原层隐藏由用户独立模块接入。

由用户操作自有 CLIP 副本。记录 CSP 版本、画布尺寸、缩放/旋转、笔刷与图层 UUID、Memoline 提交号，并保存验收前后的副本。开发自动检查继续用 fake，不向真实 CSP 注入输入或写用户配置。

用户提供的真实 `.memoline` 可用于独立的文件内代码回归：读取实际历史资产、由代码选择范围，运行精确撤销与事件编辑的计划和重建路径并比较像素。无需先完成本清单，也不以文件内回归替代 CSP 实机结果。

## 末尾封盘补充用例

代码回归覆盖：最后几笔不改变视口便停止；A 作画后切 B 触发普通捕获，再停止；末次捕获失去 CSP 前台后主动刷新；缺 PNG、第二层失败、原生结束标记后新笔/鼠标/撤销输入。成功封盘须在重读时恢复各层末图和有原生指针的脏矩阵，副层上下文不能重复拥有机械事件；失败保留原始记录及捕获目录，原工程不追加半成品。这些离线用例不记为 CSP 实机验收。

## 日志收集

现有宿主将识别器输出写到 `Memoline_demo_csponly/.work/<运行目录>/recognizer.log`；此目录名当前由 GUID 生成，不一定等于原生 sessionId。另保留原生 `.memoline.part/.memoline`、同名 `.diagnostics.jsonl` 和 `.memoline.live.json`，以及本次 watcher manifest/差异 PNG。记录请求的 requestId/transactionId、边界 appendId、sessionId 和图层 UUID 以便关联。

宿主在该工作目录保存 `edit-journal.jsonl` 并在事务 checkpoint 刷盘，封盘时打包日志及其资产。验收提交这份日志、其引用的 PNG 资产、快捷键 provision manifest、日志输出和逐字节比较报告。只有像素验证和相应事务证据完整时才填写通过。

跨会话案例另外保留工程历史读取报告、源机械流哈希与频率、冻结计划中的来源会话及图层映射，以及未知接缝的 mask/前后像素。原始事件计数与最终合格可重放事件数分别记录，不能将缺状态、缺样本或不可归属旧数据计为已支持。

请在结果栏填写日期、提交号、通过/失败和相关日志路径；失败保留现场副本及日志。
