# ScreenCanvasTransform 精度验证报告

日期：2026-09-22

## 已确认并修正的问题

修改前 `MeasureOrientedEdge` 用膨胀掩膜确定切向 `t_lo/t_hi`，只用原始红像素修正法向位置，最终端点仍来自膨胀范围。这样会把断裂连接和笔迹外扩误当成线段几何端点。

修改后膨胀掩膜只用于候选发现、粗方向和原图搜索范围。线条颜色支持、方向、中心位置和切向端点均从原始 ROI 的连续红色权重重新估计；相邻完整边使用中心线交点作为几何角点，裁切端点保留裁切语义。现有 0.2 双边恢复和导航器灰色背景包围盒修复均保留。

## 覆盖范围

- 不同线宽、抗锯齿混色、暗红色和单像素断裂；
- 独立亚像素中心位置；
- 完整边及 0.2 双边恢复；
- 多角度旋转、常用测试倍率和工作区坐标转换；
- 导航器红框围住灰色背景、垂直/水平背景带、L 形背景；
- 非零及负数屏幕原点。

用户截图若含程序覆盖层，或没有原始 ROI/采集参数，只能用于回放链路，不能替代干净采集帧的精度验证。极小导航器红框在变换放大后仍会放大原始像素测量误差；本次未使用时间滤波掩盖单帧不确定性。
