## 真实截图 OCR 空结果修复（最新）

- 使用用户截图真实运行 RapidOCR 复现 `ValueError: The truth value of an array with more than one element is ambiguous`；发生在 OCR 返回坐标数组转换阶段，不是截图失败。修复数组判空与坐标转换。
- 原复选框搜索覆盖文字本身，会把汉字方形笔画当成已勾选。改为只在文字左侧查找矩形轮廓，再分析框内笔画，保留启用状态未知。
- 工具名称优先读取当前工具属性标题；参数标签不再全部被当作工具名称候选。选项采用局部背景证据，多个选中候选时不猜第一个。
- 两个实际图片夹具使用真实模型完成 OCR、视觉分析和字段解析，没有 sidecar：
  - `selection_panel.png`：10 个文字块、工具名“僅參照編輯圖層選擇”、颜色容差 10，取样连续像素/闭合间隙/消除锯齿勾选，扩缩选区/多图层参照未勾选。
  - `brush_panel.png`：G筆、尺寸 5.4、不透明度 100、手颤修正 8、消除锯齿“弱”。
- 18 项测试通过，包括真实 OCR 数组回归、两张真实截图和 UI 错误信息展示。原有纯假数据测试不足以验证实际 OCR 接口，此次补齐。
- UI 新增“原始 OCR 文字”页，错误原因显示在状态栏和证据区，导出保留原始文本；失败帧不会被当成可跳过的已成功帧。

## 本机可重复结果

执行命令：

```powershell
$env:PYTHONPATH='csp_panel_validator'
python -m unittest discover -s csp_panel_validator/tests -v
```

结果：10 个测试全部通过，执行耗时约 55 ms。覆盖：

- 当前帧重建数值参数，下一帧消失字段不残留；
- 枚举值必须结合视觉选中证据；
- 工具属性和子工具列表冲突时输出 `ambiguous`；
- 离线 sidecar 通过与实时相同的 `RecognitionPipeline` 生成参数、brush 和 evidence；
- 负桌面原点、ROI 边界拒绝和 JSON 配置保存/加载。
- 具体窗口身份匹配、客户区捕获范围和不持久化 HWND。
- offscreen 拖拽预览、边界限制、零面积拒绝路径和用户配置重启加载。

本机解释器为 Python 3.14.5。实时运行产生的 `capture/ocr/parse/total` 耗时会写入每条 JSON 结果。当前机器是否能完成真实屏幕捕获和 CSP 实机识别，以本次依赖安装、启动和后续手工验收结果为准。

RapidOCR 真实模型冒烟测试成功：模型文件从 `rapidocr` wheel 加载，ONNX Runtime 对 `64x256` 黑色图像完成推理并返回 0 个文字块。PySide6 offscreen 主窗口创建成功，标题为 `CSP Panel Validator`，检测到 1 个屏幕。

真实 Win32 客户区捕获烟测成功：测试窗口物理客户区为 `630x360`，两次捕获均使用 `win32_printwindow_client`；窗口移动后尺寸保持一致，关闭窗口后 `inspect_window(hwnd)` 返回失效。该测试验证了窗口移动路径，不代表真实 CSP 笔刷识别准确率。
