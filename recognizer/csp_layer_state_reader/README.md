# CSP 图层识别（精简版）

这是一个独立的图层识别小程序，不修改原 `csp_layer_state_reader`。识别器和分组解析器直接取自 `csp_layer_state_reader_ocr_compare`，固定调用你截图中结果最好的 `rapidocr` 原图分支；不会额外叠加全图 CLAHE。截图按原有方式从 CSP 窗口客户区获取，并通过冻结截图框选图层面板。识别在后台线程运行，完成后将结构化行直接填入表格。

界面只显示：图层名称、截图临时 ID、类型、所在组、可见、不透明度、混合模式。识别完整张面板后会复核高亮行、清理默认图层名中确认属于 OCR 的波浪线/前置序号，并一次性按组关系填表。蓝色高亮无论落在组行还是普通图层行，都会作为当前选中项，并在表格中高亮该行。ID 形如 `visual-row-0001`，是本次截图按顺序生成的临时编号，并非 CSP 内部 ID。

## 使用

1. 打开 CLIP STUDIO PAINT。
2. 双击 `start.bat`。
3. 点击“选择窗口并框选图层面板”，在冻结画面中拖框覆盖上方功能栏和完整图层列表，按 Enter。关键事件检测需要功能栏也在框内。
4. 点击“识别 / 刷新”单次读取，或设置截图间隔后点击“开始连续读取”。

连续模式中，截图与 OCR 使用独立后台线程池；OCR 忙时截图继续，待处理画面只保留最新一帧，避免积压旧截图。停止后不再启动新截图，已开始的识别会正常结束。

## 关键事件记录

连续截图会另用一个后台线程比较相邻画面。功能栏按钮出现高亮或蒙版按钮状态改变时，程序保留变化前画面，继续观察图层列表；只有列表中图层、组或蒙版缩略图发生结构变化才保存。仅按钮高亮而列表不变时不保存。创建图层蒙版时，新增的蒙版缩略图也会触发保存。

每个事件保存在 `关键事件记录` 下的独立文件夹，包含 `before.png`、`after.png` 和 `event.json`。主界面下方显示已保存数量，点击“打开关键事件记录”可查看。截图间隔会影响短暂高亮的捕获机会；需要监测快速操作时可选 0.5 秒。

程序优先使用本机已安装的识别环境；找不到时会在本文件夹创建 `.venv` 并安装 `requirements.txt` 中的依赖。
